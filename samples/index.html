SVG samples

Output from svg-renderer.js, which draws the same render list the canvas does. Nothing on the site uses it yet; the first intended use is PDFs of the Sun/Star overlay. Regenerate with node tools/svg-sample.mjs.

These are real SVG, so they scale without redrawing — open one on its own and zoom in as far as you like.
